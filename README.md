# Baaraath

Event booking platform built with Next.js, TypeScript, Tailwind CSS, and Prisma.

## Documentation

- [Setup Guide](./SETUP.md) — Installation, database setup, and dummy data instructions

## Quick Start

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

See [SETUP.md](./SETUP.md) for detailed steps and demo accounts.
